# Sikkerhetskopier

Denne mappen er bevisst tom i Git. Sikkerhetskopier inneholder personlige
innstillinger og skal aldri sjekkes inn.

`scripts/map-mint.sh` lagrer dem lokalt i
`~/.local/share/mint-ro/backups/<dato-tid>/` (eller `$XDG_DATA_HOME/mint-ro/backups/`).
Se hovedfilen [README.md](../README.md#sikkerhetskopi-og-gjenoppretting).
